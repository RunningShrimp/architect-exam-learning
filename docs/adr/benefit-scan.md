# 阶段 1 · 受益点盘点（React / Three.js 引入评估）

逐页类型扫描结论：62 页交互分四类——判题（单次点击改 DOM）、动画（makeAnim 四控 + 每帧重绘 SVG/Canvas）、
实验室（拖拽/配对/滑块）、进度读写（localStorage 全量 JSON，页面级一次）。无跨页共享可变状态、无列表 diff、
无高频重渲染场景。

## 强 3D 候选（空间概念 · 双重编码/具身认知）

| 页 | 增强点 | 现有 2D 实现 | 3D 预期增益 | 价值分级 |
|---|---|---|---|---|
| 05 存储层次 | Cache→内存→磁盘金字塔可旋转 | 命中率曲线 + 访问路线动画（2D） | 层级"高低"已有 2D 隐喻；旋转增益存疑 | 中低 |
| 04 流水线 | 时空图三维化（指令×周期×段） | 甘特式 2D 时空图（教材标准表达） | 第三维=指令序，2D 已表达 | 低 |
| 20/22 网络分层与拓扑 | 分层栈/拓扑 3D | 2D 分层表 + 端到端旅程动画 | 真题以 2D 图考查，3D 表达非考核形态 | 低 |
| 34-36 架构风格 | 风格演化"三维谱系" | 对比表 + 流动对比动画 | 抽象概念无空间本征结构 | 低 |
| 12 页表/Cache 映射 | 直接映射组相联的"行×组"结构 | 2D 映射冲突模拟器 | 组相联有一定空间性，唯一中上候选 | 中 |

## 弱 3D/动效候选（默认不立项）

粒子背景、页面转场、卡片悬浮 3D——无学习效果指向，违反北极星。**0 立项**。

## React 类候选（复杂状态/高频重渲染）

| 页 | 场景 | 状态复杂度 | 结论 |
|---|---|---|---|
| review | 到期队列+混合卷+错题本 | 三块独立渲染，一次性构建，无 diff 需求 | 不需要 |
| index | 仪表盘+雷达+折叠列表 | 单次注入 | 不需要 |
| kp/* | 判题/费曼关键词点亮 | 点击→改类名，O(n) 直接 DOM | 不需要 |

**React 受益点：0 个**（如实盘点）。

## 结论（进入阶段 2 的假设，待实测与 POC 检验）

- React：无真实受益点，仅在"与 Three.js 同栈"时才被连带讨论。
- Three.js：唯一达到"中"级的候选是 12（组相联映射）与 05（金字塔），以 05 为 POC 页
  （它有现成 2D 动画可并排对比，最能回答"3D 多教会了什么"）。
