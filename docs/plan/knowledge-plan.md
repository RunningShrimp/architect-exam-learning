## 3. 高频易错点清单（E路，按域分发到生成代理）

- 流水线：理论公式 vs 实践公式 (k+n-1)Δt；周期取最长段。
- Cache：同时访问 vs 先Cache后主存两种口径；h×t1+(1-h)×t2。
- 可靠性：并联失效率不可直接相加；MTBF=MTTF+MTTR；混联先拆层。
- 子网：可用主机 2^n-2；主机号不可全0全1。
- 关键路径：总时差=LS-ES；关键活动总时差为0；自由时差≠总时差。
- 内聚低→高：偶然/逻辑/时间/过程/通信/顺序/功能；耦合强→弱（低→高耦合）：非直接/数据/标记/控制/外部/公共/内容。
- 概念对：装饰器vs代理、桥接vs适配器、状态vs策略（看意图不看结构）；SAAM(可修改性,最早) vs ATAM(多属性权衡)；风格vs模式vs惯用法分层。
- 案例失分：DFD 补流漏名称/方向、平衡论证不全；质量属性场景六要素必须逐条可量化；规范化只给结论不给推导理由=丢分。

## 4. 口诀素材库（D路，来源标注见检索报告；「自拟」项生成代理可润色）

- 穿透/击穿/雪崩：**穿透库里无，击穿单个热，雪崩一大片**。
- PV：停车场比喻——S=剩余车位数；P=占位，V=放行；S为负的绝对值=排队数。
- 脏读/不可重复读/幻读：**脏听听反悔，重复值会变，幻影数会多**。
- 敏感/权衡/风险：**一个属性是敏感，多个属性要权衡，决策隐患是风险**。
- 内聚七级：**偶逻时过通顺功**（低→高）；耦合七级（低→高）：**非数标控外公内**。
- 管道过滤器=水厂流水线（数据驱动、不认识上下游）；主子程序=老板点将（控制权在主程序）。
- 事件驱动=公众号发布-订阅（互不认识）；观察者=班群直接@。
- MVC=餐厅：厨师(Model)/菜单摆盘(View)/服务员(Controller)。
- 缓存=社区便利店（全站统一，见 PAGE-SPEC §5）；LRU=最久没人买的先下架。
