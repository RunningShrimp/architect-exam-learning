第7站，中断、DMA与总线。下面朗读知识卡片。小节，是什么。I/O 控制方式。回答一个问题：外设和 CPU 怎么协作？三档答案，。程序查询。（CPU 主动轮询干等）、。中断。（外设主动通知，CPU 与外设并行）、。DMA。（DMAC 接管总线，数据不经 CPU 直接在设备与内存间成块搬运）。它们跑的「马路」就是。总线。：数据总线传内容、地址总线传门牌、控制总线传命令与时序。小节，解决什么问题。CPU 快、外设慢，差好几个量级。轮询让最快的部件陪最慢的部件空转；中断让「等」变成「被叫」；DMA 连搬运都不劳烦 CPU，逐级把 CPU 从低效等待中解放出来。小节，核心机制。中断全流程。：外设发中断请求 到 中断判优（多请求选最高优先级） 到 CPU 在。一条指令执行结束。时响应 到 保护现场（保存断点 PC 与寄存器） 到 取。中断向量。（查中断向量表得服务程序入口） 到 执行中断服务程序 到 恢复现场 到 中断返回断点。多重中断（嵌套）。：优先级更高的请求可以打断低级服务程序；屏蔽字用来「本服务程序运行期间暂时挡住哪些级别」。DMA 流程。：CPU 向 DMAC 写入（源址、目的址、长度、方向）后继续干活 到 DMAC 申请总线使用权，。周期挪用/窃取。方式与 CPU 轮流用总线 到 成块搬运不经 CPU 到 传输结束 DMAC 发一次中断通知 CPU 收尾。小节，关键细节。来看一张对照表。表的栏目有：CPU 占用、数据路径、适用。先看程序查询：CPU 占用是100% 干等；数据路径是设备 到 CPU 到 内存；适用是极简单/慢速场景、无中断硬件的裸机。先看中断：CPU 占用是仅服务程序期间占用；数据路径是设备 到 CPU 到 内存（每字节/字都过 CPU）；适用是键盘、鼠标等低速随机事件。先看DMA：CPU 占用是仅初始化+结束中断；数据路径是设备 与 内存直达；适用是磁盘、网卡等成块高速传输。表格就是这些，抓住每行的差异点，就抓住了考点。总线仲裁。（多个主设备抢总线）：集中式三种，链式查询（优先级固定串行传递，省线但低优先级可能饿死）、计数器定时查询（按计数轮询）、独立请求（每设备专线，最快最贵）。总线带宽。等于 工作频率 乘以 总线宽度 除以 8，例：100MHz 乘以 32bit 除以 8 等于 400 MB/s。易错点。第一，「DMA 不需要 CPU」说过了头：DMA 结束后。仍要以中断方式。
