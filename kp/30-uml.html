2先想后学：真实工程场景

🏗️ 场景工地例会上，业主指着两本图册问：一本是「结构竣工照」——梁柱板墙怎么连接；另一本是「施工过程录像」——先立塔吊、再绑钢筋、后浇筑。总工说：软件建模也一样，UML 的十几种图无非「拍照片」和「拍录像」两大类。那问题来了： ATM 取款必须「先登录」，余额不足时「打印提醒凭条」——这两件事在用例图里该怎么画？箭头各指向谁？
💡 点开看思路与答案

「先登录」是取款必然包含的步骤 → include：箭头从基用例「取款」指向被包含用例「登录」。「打印提醒」只在条件发生（余额不足）时才执行 → extend：箭头从扩展用例「打印提醒」指向基用例「取款」。方向记法：include 箭头离开基用例，extend 箭头指回基用例。这是 UML 一节最高频的考点。

3知识卡片

是什么

UML（统一建模语言）是面向对象建模的「制图国标」：工地上的建筑图有统一图例，UML 给软件模型规定了统一图例。图分两大类——静态图（结构图）拍骨架照：系统某个时刻长什么样；动态图（行为图）拍过程录像：系统随时间怎么运转。

核心机制 1：图的动静归类

类别图记法
静态（结构）图类图、对象图、构件图、部署图、包图、组合结构图「类对构件部署包，组合结构拍骨架」
动态（行为）图用例图、活动图、状态机图、顺序图、通信图、定时图、交互概览图「用例状态加活动，四种交互拍录像」

口径说明：顺序图、通信图、定时图、交互概览图合称交互图；对用例图的归类教材间有分歧——多数教材按其表达系统外部行为的性质归入「行为（动态）图」，本站采用此口径并在此注明。

核心机制 2：用例图三关系（最高频）

  • include 包含：基用例必然执行被包含用例。例：取款 include 登录。箭头：基用例 → 被包含用例（虚线箭头，标 include）。
  • extend 扩展：扩展用例在条件满足时可选执行。例：余额不足时打印提醒凭条。箭头：扩展用例 → 基用例（虚线箭头，标 extend）。
  • generalize 泛化：一般→特殊，如「取款」与「手机取款」。箭头：子用例 → 父用例（实线三角）。

核心机制 3：类图六关系强度排序

强度（弱→强）关系含义大雁生活例
1依赖临时用一下（方法参数/局部变量）大雁迁徙时「借道」某个湖泊
2关联长期知道对方（成员变量）大雁与驯养员长期相识
3聚合整体-部分，可分离（空心菱形）大雁—雁群：散伙各自能活
4组合整体-部分，同生共死（实心菱形）大雁—翅膀：雁亡翅不存
5泛化 = 实现is-a 继承 / 实现接口（实线/虚线三角）大雁是一种鸟；大雁实现「会飞」接口

排序：依赖 < 关联 < 聚合 < 组合 < 泛化 = 实现。泛化与实现强度视为同级，区别在：泛化继承「类」，实现兑现「接口承诺」。

关键细节：两对「录像」的分工

  • 顺序图 vs 通信图：同为交互图，语义等价。顺序图以生命线+垂直时间轴突出消息的时间顺序；通信图以对象链接网突出对象间的结构组织（消息用序号编排）。
  • 状态机图 vs 活动图：状态机图描述单个对象因事件在状态间变迁（一部电梯的门态）；活动图描述跨对象的工作流，像带分叉汇合、泳道的流程图（施工审批流程）。
⚠️ 易错点①include/extend 的箭头方向与「必须/可选」配对是最常见的坑：include 箭头由基指向被包含，extend 箭头由扩展指向基；②聚合与组合只看一句：散了还能活=聚合，一亡俱亡=组合；③部署图、构件图是静态图，别被「部署像动作」带偏；④用例图的参与者是人/外系统等外部角色，不是系统内部模块。
🔤 专业英语use case 用例 · include/extend 包含/扩展 · generalization 泛化 · sequence diagram 顺序图 · state machine diagram 状态机图

4生活类比与口诀

UML = 工地的制图国标：静态图是结构竣工照（梁柱怎么连=类怎么关联），动态图是施工过程录像（先干什么后干什么=消息怎么传）。用例图是给业主看的「服务承诺书」：承诺里必然包含的步骤写进 include，临时加赠的服务写 extend。

类比项概念项成立/失效
结构竣工照类图/对象图/部署图等静态图成立
施工过程录像顺序图/活动图/状态机图等动态图成立
开工前必办的「动工许可证」include（必然包含）成立
下雨才追加的「防雨棚」extend（条件可选）成立
塔吊与工地：拆了塔吊工地照样是工地聚合成立
录相对拍得清楚，两盘录像带内容必然不同顺序图与通信图失效：二者语义等价，只是呈现重点不同（时间 vs 结构）
类构对象部署包，组合结构静态照；
用例状态加活动，顺序通信定时交互；
包含必走指向被含，扩展可选指回基座；
依关聚组泛实现，强度一级一级高。

10小结

  • ① 图分动静：静态六图拍骨架照，动态七图拍录像（用例归行为图，注明口径分歧）。
  • ② 用例图三关系：include 必然（箭头指向被含）、extend 可选（箭头指向基）、泛化 is-a。
  • ③ 类图六关系弱→强：依关聚组泛=实现；聚合空心可分离，组合实心同生灭。
