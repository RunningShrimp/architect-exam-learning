07 · 中断、DMA与总线

1一句话核心

外设按门铃（中断），大件自己搬（DMA），公共道路是总线。

2先想后学：真实工程场景

🏗️ 场景嵌入式新人写的采集程序：主循环里不停读磁盘状态寄存器等数据就绪，结果 4 核 CPU 其中一核常年 100%，而系统吞吐只有几 MB/s。前辈看了一眼说：「你在用轮询等外卖，正确姿势是让外卖到了按门铃——大件行李还可以让快递员直接搬进库房。」三种 I/O 方式各是什么？CPU 占用差距有多大？
💡 点开看思路与答案

他写的是程序查询：CPU 反复读状态寄存器干等，占用 100%；改成中断：外设就绪后主动发信号，CPU 干自己的活，被叫到才处理，占用骤降；数据量大时再上DMA：DMA 控制器（DMAC）接管总线，数据在设备与内存之间直接搬运，CPU 只在开始前配置、结束后收一次中断——「快递员直接搬进库房，签收时叫你一声」。三种方式是 CPU 时间与硬件复杂度之间的逐级交易，本页动画把它画成甘特图。

3知识卡片

是什么

I/O 控制方式回答一个问题：外设和 CPU 怎么协作？三档答案——程序查询（CPU 主动轮询干等）、中断（外设主动通知，CPU 与外设并行）、DMA（DMAC 接管总线，数据不经 CPU 直接在设备与内存间成块搬运）。它们跑的「马路」就是总线：数据总线传内容、地址总线传门牌、控制总线传命令与时序。

解决什么问题

CPU 快、外设慢，差好几个量级。轮询让最快的部件陪最慢的部件空转；中断让「等」变成「被叫」；DMA 连搬运都不劳烦 CPU——逐级把 CPU 从低效等待中解放出来。

核心机制

中断全流程：外设发中断请求 → 中断判优（多请求选最高优先级）→ CPU 在一条指令执行结束时响应 → 保护现场（保存断点 PC 与寄存器）→ 取中断向量（查中断向量表得服务程序入口）→ 执行中断服务程序 → 恢复现场 → 中断返回断点。多重中断（嵌套）：优先级更高的请求可以打断低级服务程序；屏蔽字用来「本服务程序运行期间暂时挡住哪些级别」。

DMA 流程：CPU 向 DMAC 写入（源址、目的址、长度、方向）后继续干活 → DMAC 申请总线使用权，周期挪用/窃取方式与 CPU 轮流用总线 → 成块搬运不经 CPU → 传输结束 DMAC 发一次中断通知 CPU 收尾。

关键细节

方式CPU 占用数据路径适用
程序查询100% 干等设备→CPU→内存极简单/慢速场景、无中断硬件的裸机
中断仅服务程序期间占用设备→CPU→内存（每字节/字都过 CPU）键盘、鼠标等低速随机事件
DMA仅初始化+结束中断设备↔内存直达磁盘、网卡等成块高速传输

总线仲裁（多个主设备抢总线）：集中式三种——链式查询（优先级固定串行传递，省线但低优先级可能饿死）、计数器定时查询（按计数轮询）、独立请求（每设备专线，最快最贵）。总线带宽 = 工作频率 × 总线宽度 ÷ 8，例：100MHz × 32bit ÷ 8 = 400 MB/s。

⚠️ 易错点①「DMA 不需要 CPU」说过了头：DMA 结束后仍要以中断方式通知 CPU；②中断响应时机是「一条指令执行结束」，不是任意时刻；③DMA 请求的总线优先级通常高于普通 I/O 中断（成块传输不能被零敲碎打地打断）；④带宽计算记得「宽度是 bit，带宽要 MB/s」，除以 8 是必做动作。

专业英语小贴士

interrupt（中断）；interrupt vector（中断向量）；ISR = Interrupt Service Routine（中断服务程序）；DMA = Direct Memory Access（直接存储器存取）；cycle stealing（周期挪用/窃取）；bus arbitration（总线仲裁）。

4生活类比与口诀

你在屋里办公（CPU），水壶在厨房烧水（外设）：程序查询是你每 10 秒跑去厨房看一眼——水没开白跑，水开了也可能错过；中断是装了个门铃，水开自动响，你手头这句写完再去关火；DMA是请了个小时工（DMAC），整桶水直接搬进库房，搬完按一次门铃让你验收。大家的必经之路是走廊（总线），两家同时要过走廊就得有人协调（总线仲裁=交警）。

类比项概念项成立/失效
反复跑厨房看水开程序查询轮询成立
门铃响了才去处理中断请求与响应成立（门铃=中断信号）
小时工搬水你全然不知DMA 全程不占 CPU失效：DMA 开始前要你交代、结束后仍按门铃通知你——初始化与收尾离不开 CPU
走廊想走就走总线随意使用失效：多个主设备要经仲裁轮流使用总线
查询干等最笨拙，中断门铃手头活；
DMA 是搬运工，成块直达不啰嗦；
响应须等指令毕，嵌套要看优先级；
带宽频率乘宽度，记得除八换单位。

10小结

  • ① 三种 I/O 方式是 CPU 解放三级跳：轮询全占、中断按门铃、DMA 连搬运都外包。
  • ② 中断流程七步走，响应在指令执行结束，优先级+屏蔽字决定嵌套秩序；DMA 结束仍要发中断。
  • ③ 总线是公共马路：数据/地址/控制三线，仲裁定先后，带宽=频率×宽度÷8。
