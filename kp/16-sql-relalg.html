16 · SQL与关系代数

1一句话核心

选择挑行、投影挑列、连接拼表、除法问「全部都」。

2先想后学：真实工程场景

🏗️ 场景档案馆来了条新规：馆长要一份「借阅过馆里全部珍藏本的读者」名单。新人小张写成 SQL 后逻辑绕晕了；老馆员说：「这种『全部都…』的问题，关系代数里一个符号就写完了。」什么符号？它和 SQL 里的双重否定（两层 NOT EXISTS）是什么关系？
💡 点开看思路与答案

那个符号是除法 ÷。「查询选修了全部课程的学生」「查询供应了全部零件的供应商」「查询借阅了全部珍藏本的读者」，全是同一个模板：设 R(读者,物品)、C(全部物品清单)，答案 = π读者(R) ÷ π物品(C)。SQL 没有除法运算符，要翻译成「不存在一件珍藏本是他没借过的」——两层 NOT EXISTS 的双重否定。本页把 σ、π、⋈、÷ 与 SQL 子句一一对上。

3知识卡片

是什么

关系代数是以关系（表）为运算对象的代数系统：输入表、输出表。五个基本运算：并（∪）、差（−）、笛卡尔积（×）、选择 σ（按条件挑行）、投影 π（挑列并去重）；再派生交（∩）、连接 ⋈（按条件把两表横向拼接）、除法 ÷、重命名（ρ）。SQL 是它的人类可读版：一条 SELECT 语句翻译成一棵关系代数表达式树。

解决什么问题

「怎么查」可以写得很啰嗦也可能很巧，关系代数给出一套最小而完备的查询词汇，让「任意复杂查询都能由这几个运算组合出来」有数学保证；同时它是查询优化的语言——两条写法不同的 SQL 若代数等价，DBMS 就能改写成代价更低的那个。

核心机制：符号对照表

关系代数含义SQL 对应记忆钩子
σ条件(R)选择：挑满足条件的行WHEREσ 横着切
π列(R)投影：挑列（结果自动去重）SELECT 列（+DISTINCT 才去重）π 竖着切
R ⋈ S连接：按条件横向拼表；自然连接按同名属性等值且去重列JOIN ... ON⋈ 横向焊接
R ÷ S除法：「与 S 中每一个都有关」的 R 元组无直接语法，用两层 NOT EXISTS / COUNT÷ 问「全部都」
∪ − ∩并、差、交（要求同目：列数与类型一致）UNION / EXCEPT / INTERSECT集合老三样

关键细节：除法经典例

表 SC(学号,课程号)、表 Course(课程号)。查询选修了全部课程的学生学号：

关系代数：π学号,课程号(SC) ÷ π课程号(Course)
SQL（双重否定）：SELECT DISTINCT 学号 FROM SC X
WHERE NOT EXISTS
  ( SELECT * FROM Course C WHERE NOT EXISTS
    ( SELECT * FROM SC Y WHERE Y.学号 = X.学号
      AND Y.课程号 = C.课程号 ) );

读法：「选出这样的学生——不存在一门课是他没有选的。」除法是差、投影、笛卡尔积的组合糖：π学号(R) − π学号((π学号(R) × π课程号(C)) − R)。

⚠️ 易错点① σ 与 π 别混：σ 挑行（横切）、π 挑列（竖切）。② 纯代数的 π 天然去重，SQL 的 SELECT 不去重，要 DISTINCT——考题爱在这里设坑。③ 连接≠笛卡尔积：× 是全配对（行数相乘），⋈ 只保留满足条件的配对，自然连接还会去掉重复列。④ 除法被除数要投影成「（查询对象, 关联列）」，多带无关列结果恒为空。
🇬🇧 专业英语小贴士selection（选择）、projection（投影）、join（连接）、division（除法）；SQL = Structured Query Language（结构化查询语言）。

4生活类比与口诀

回到 📚 中央档案馆：查档案就是一个代数流水线——选择 σ 是管理员按条件把不合要求的档案抽走（挑行）；投影 π 是只抄你要的栏目（挑列）；连接 ⋈ 是把两本登记簿按编号对齐拼在一起；除法 ÷ 最特别：「找出借过所有珍藏本的读者」，要一个读者对着一整份清单逐一核对，一个不落才算数。

类比项概念项成立/失效
按条件抽走不合格档案σ 选择（挑行）成立
只抄需要的栏目π 投影（挑列）成立；但现实抄写不去重，代数投影自动去重
两本登记簿按编号对齐拼合⋈ 连接成立
「全读过书单才算读书之星」÷ 除法成立；失效边界：清单一变（新书入库），「读书之星」名单可能立刻变空——除法结果依赖「被除清单」的当前内容
西格玛横切来挑行，派竖切选列忙；
连接对号拼好表，并差交集同目装；
若问全部都做过，除法登场才能扛；
双重否定两层滤，NOT EXISTS 才周详。

易混概念对比

笛卡尔积 ×连接 ⋈
结果行数n × m 全配对只保留满足连接条件的配对
重复列全部保留自然连接会去掉同名重复列
易错点以为 JOIN 就是 ×忘写 ON 条件会退化成笛卡尔积，行数爆炸

10小结

  • ① 五运算记号：σ 挑行、π 挑列、⋈ 拼表、∪−∩ 集合、÷ 问「全部都」。
  • ② SQL ↔ 代数：WHERE↔σ、SELECT 列↔π、JOIN ON↔⋈、「全部都」↔÷（SQL 用两层 NOT EXISTS 双重否定）。
  • ③ SQL 的 SELECT 不自动去重，代数投影去重；逻辑执行顺序 FROM→WHERE→GROUP BY→HAVING→SELECT→ORDER BY。
