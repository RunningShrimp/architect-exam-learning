13 · 文件系统与设备管理

1一句话核心

文件目录管名字，索引节点管货位，磁盘调度让磁头少跑冤枉路。

2先想后学：真实工程场景

🏗️ 场景某图片存储服务报警「No space left on device」。运维上机一查：df 显示磁盘块只用了 40%，明明还有大把空间，但任何新文件都创建不了；du 顺带统计出文件总数高达五千万个 3~10KB 的小图。问题：磁盘明明「没满」，为什么写不进去？
💡 点开看思路与答案

「空间」在文件系统里是两种资源：数据块（装文件内容）和 inode（索引节点）（装文件元数据）。每个文件都要占用一个 inode——五千万个小文件把 inode 先耗光了，块还有 40% 也照样建不了文件。用 df 看块用量、用 df -i 看 inode 使用率一对照即可验证。这个案例是本页两条主线的交汇：inode 管什么、怎么算容量；文件建在磁盘哪个块上、谁来管理空闲块。

3知识卡片

是什么

文件系统管两件事：命名与放置。文件目录是「文件名 → inode 号」的检索表（逻辑视图）；索引节点 inode 是文件的登记卡——记录大小、权限、时间与全部数据块指针（物理视图）；空闲块由位示图等结构管理；设备管理则回答「数据怎么在慢速设备上高效进出」。文件的逻辑结构是给用户看的组织方式（顺序文件、索引文件），物理结构是它在磁盘块上的真实摆放（连续、链接、索引）。

解决什么问题

海量文件怎么命名不冲突、按名能找到；磁盘块怎么分配、空闲怎么记；磁盘是机械慢设备（寻道占访问时间大头），多个请求来了按什么顺序服务。

核心机制一：物理结构对比

物理结构做法优点缺点
连续分配文件占连续磁盘块支持随机存取，顺序读快难扩展、产生外部碎片
隐式链接每块尾带下一块指针无外部碎片，易扩展只能顺链存取，断链全毁
显式链接（FAT）链接表集中成 FAT 表查表即知链路，FAT 可进内存FAT 本身占空间
索引分配每文件一张索引块（块号数组）支持随机存取、易扩展小文件也占一个索引块；大文件需多级/混合索引

UNIX 的 inode 是混合索引的典范：直接地址 + 一级间接 + 二级间接（有的还有三级）。计算公式：每块可存地址数 = 块大小 ÷ 地址项大小；最大文件 = 直接块数 + 每块地址数 × 1（一级）+ 每块地址数² × 1（二级），单位是块。

核心机制二：位示图（空闲块管理）

用一串二进制位标记每个盘块：0 空闲 1 占用（或相反，看题目约定）。块号 b → 字号 = ⌊b ÷ 字长⌋，位号 = b mod 字长（本页按从 0 编号口径）；反向：块号 = 字号 × 字长 + 位号。做这类题先确认题目从 0 还是从 1 编号。

核心机制三：磁盘调度

算法规则特点
FCFS按到达顺序公平但寻道长
SSTF 最短寻道优先每次选离磁头最近的平均寻道短；远端请求可能饥饿
SCAN 电梯沿当前方向服务到头（端点）才折返等待时间有界、公平
C-SCAN单向服务，到端后快速回扫到另一端继续单向各磁道等待更均匀

磁盘存取时间 = 寻道时间 + 旋转延迟 + 传输时间。变体 LOOK/C-LOOK 到「最远请求处」即折返，不到物理端点——做题必须看题干给哪种口径；C-SCAN 回扫那一段是否计入移动道数，教材口径不一，同样看题干。

核心机制四：设备管理

I/O 控制方式演进：程序查询（CPU 干等）→ 中断（每传一段 CPU 介入一次）→ DMA（DMA 控制器整块搬运，CPU 只在开始初始化与结束中断时介入）→ 通道（专用处理器，能执行通道程序）。缓冲用内存蓄水池缓和 CPU 与设备速度差、减少中断次数（单/双/循环缓冲与缓冲池）；Spooling 假脱机用磁盘排队把独占设备改造成「共享设备」（如打印队列），也是破坏死锁「互斥」条件的经典手段。

专业英语小贴士

inode（索引节点）、Seek Time（寻道时间）、Spooling = Simultaneous Peripheral Operations On-Line（假脱机）。

⚠️ 易错点 ① 「还有空间却建不了文件」≠ 块耗尽，可能是 inode 耗尽：df 看块、df -i 看 inode。
② SCAN 是「到端点才折返」，LOOK 是「到最远请求就折返」——两者移动道数不同，审题先抓口径。
③ 位示图与磁道编号可能从 0 也可能从 1 起，公式两端口径必须一致。
④ SSTF 会饿死远端请求；DMA 期间 CPU 不是「完全空闲」，它与传输并行执行别的进程，只在首尾被叫。

10小结

  • ① 文件系统三层分工：目录管「名字→inode」，inode 管「内容→块号」（直接+间接混合索引），位示图管「哪些块空着」。
  • ② 磁盘调度四件套：FCFS 公平慢、SSTF 快但饿远客、SCAN 电梯到端点才折返、C-SCAN 单向服务最均匀；审题先抓「端点/口径」。
  • ③ 设备管理主线是「让 CPU 少等」：中断 → DMA → 通道一路卸载，缓冲削峰填谷，Spooling 把独占设备变共享。
